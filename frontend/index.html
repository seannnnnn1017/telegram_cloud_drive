跨裝置同步

透過 Telegram MTProto API 掃描頻道歷史，將其他裝置上傳的檔案匯入此資料庫。
1. 至 my.telegram.org 取得 API ID / Hash，填入後儲存。
2. 在終端機執行 telecloud sync-auth 完成手機 OTP 認證（一次性）。
3. 回到此頁按同步按鈕即可。
